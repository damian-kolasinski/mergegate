# Cases for `remap::map`, run by lines_tests.rs. Each case is a name line, then
# `old:` and `new:` with a file's lines as words, `lines:` with the range on
# the old side, and `want:` with `same A-B`, `changed A-B` or `gone`. The diff
# between them is computed as at submit.

lines above a change stay where they are
old: a b c d e
new: a b c d E
lines: 1-2
want: same 1-2

lines below an added line move down
old: a b c d e
new: x a b c d e
lines: 2-3
want: same 3-4

lines far below a change move by what it added and removed
old: a b c d e f g h i j k l m n o p q r s t
new: a B1 B2 B3 c d e f g h i j k l m n o p q r s t
lines: 17-19
want: same 19-21

lines between two changes move by the first only
old: a b c d e f g h i j k l m n o p q r s t
new: a c d e f g h i j k l m n o p q r s t U
lines: 9-10
want: same 8-9

a changed line maps to its replacement
old: a b c d e
new: a B c d e
lines: 2-2
want: changed 2-2

a range with a changed line keeps the rest around it
old: a b c d e
new: a B c d e
lines: 1-3
want: changed 1-3

a line replaced by several maps to all of them
old: a b c
new: a X Y Z c
lines: 2-2
want: changed 2-4

deleted lines with nothing in their place are gone
old: a b c d e
new: a d e
lines: 2-3
want: gone

a deleted last line is gone
old: a b c
new: a b
lines: 3-3
want: gone

a range losing some lines keeps the others
old: a b c d e
new: a d e
lines: 1-3
want: changed 1-1

a line added inside the range changes it
old: a b c
new: a x b c
lines: 1-2
want: changed 1-3

a line added right before the range leaves it unchanged
old: a b c
new: a x b c
lines: 2-3
want: same 3-4

a line added right after the range leaves it unchanged
old: a b c
new: a x b c
lines: 1-1
want: same 1-1

an unchanged file maps every line to itself
old: a b c
new: a b c
lines: 1-3
want: same 1-3
